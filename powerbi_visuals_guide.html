Power BI Visuals — What Each One Does

A simple guide to the visuals in Power BI. Each icon shows what the visual looks like, what it is used for, and what kind of data works best with it.

Charts for comparing numbers

Stacked Bar Chart

Use it for:Comparing totals across groups, with each bar split into parts.
Works best with:One category (like region or product) and a few sub-categories that add up to a whole.

Clustered Column Chart

Use it for:Comparing values across different categories side by side.
Works best with:A few categories (like months or products) with one or two numbers to compare.

Clustered Bar Chart

Use it for:Same as column chart, but bars go sideways — good for long category names.
Works best with:Categories with long text labels, like job titles or full product names.

Line Chart

Use it for:Showing how a number changes over time — going up, down, or staying flat.
Works best with:Time-based data, like sales by month or website visits by day.

Line and Column Chart (Combo)

Use it for:Showing two related numbers together — one as bars, one as a line.
Works best with:Data like "sales" (bars) and "profit margin %" (line) over the same time period.

Area Chart

Use it for:Like a line chart, but the space under the line is filled in — makes trends feel bigger.
Works best with:Time-based data where you also want to show volume or size, like total revenue over years.

Stacked Area Chart

Use it for:Showing how several groups add up to a total, over time.
Works best with:Time data split into categories, like revenue by product line across years.

Ribbon Chart

Use it for:Showing which category ranks highest, and how the ranking changes over time.
Works best with:Ranked categories over time, like "which product sold the most each month."

Waterfall Chart

Use it for:Showing how a starting number goes up and down in steps to reach a final number.
Works best with:Financial data, like profit that increases from sales and decreases from costs.
Charts for parts of a whole

Funnel Chart

Use it for:Showing steps in a process where numbers drop at each stage.
Works best with:Sales pipelines or sign-up steps, like "visitors → sign-ups → paying customers."

Pie Chart

Use it for:Showing how a total splits into a few parts, as percentages.
Works best with:A small number of categories (2-6) that together make up 100%.

Donut Chart

Use it for:Same as a pie chart, but with a hole in the middle — often used to also show a total number.
Works best with:The same kind of data as a pie chart: a few categories making up a whole.

Treemap

Use it for:Showing parts of a whole using different sized boxes — bigger box means bigger value.
Works best with:Many categories where you want to spot the biggest ones quickly, like sales by product category.
Charts for relationships and patterns

Scatter Chart

Use it for:Showing the relationship between two numbers, and spotting patterns or outliers.
Works best with:Two number fields, like "price vs sales" or "age vs income," often with a third number as dot size.

Gauge

Use it for:Showing progress toward a single goal, like a speedometer.
Works best with:One number compared to a target, like "sales achieved vs sales target."

Map / Filled Map

Use it for:Showing data by location, either as pins on a map or shaded regions.
Works best with:Location data, like country, state, or city, paired with a number (sales by state).
Showing raw numbers and text

Card

Use it for:Showing one single big number, like a total or a count.
Works best with:A single summary value, like "Total Revenue" or "Total Orders."

Multi-row Card

Use it for:Showing several single numbers together, one under another.
Works best with:A few summary values you want side by side, like total sales, total cost, and total profit.

KPI

Use it for:Showing a number alongside its trend and a goal, with a small trend line.
Works best with:A performance number tracked over time against a target, like "monthly sales vs goal."

Table

Use it for:Showing raw data in plain rows and columns, like a spreadsheet.
Works best with:Detailed, list-style data where people need to read exact values, like an order list.

Matrix

Use it for:Like a table, but lets you group data by rows and columns, with subtotals — similar to an Excel pivot table.
Works best with:Data you want to break down two ways at once, like "sales by region and by month."
Filtering and interacting

Slicer

Use it for:Letting people pick a value and filter everything else on the page (like a dropdown or checkbox list).
Works best with:Categories people will want to filter by, like year, region, or product name.

Q&A

Use it for:Letting people type a plain-English question and get an answer as a chart automatically.
Works best with:Well-labeled data with clear field names, so the question can be understood correctly.

Decomposition Tree

Use it for:Breaking down a big number into its causes, branch by branch, so you can dig into "why."
Works best with:A total number that can be split by many categories, like total sales by region, then by product, then by customer.

Key Influencers

Use it for:Finding out which factors most affect a result, in plain sentences (like "customers churn more when support tickets are high").
Works best with:Data with one clear outcome column (like "churned: yes/no") and several possible causes.

Smart Narrative

Use it for:Automatically writing a short text summary that explains what the numbers on the page mean.
Works best with:Any report page where you want a plain-language takeaway next to the charts.
Advanced and custom visuals

R Script Visual

Use it for:Drawing a custom chart using the R programming language, for advanced statistics.
Works best with:Data needing complex statistical analysis that standard visuals can't do, like custom forecasting models.

Python Visual

Use it for:Same idea as the R visual, but using Python code to build a custom chart.
Works best with:Advanced data science tasks, like machine learning results or custom plots.

Custom Visuals (from marketplace)

Use it for:Adding chart types Power BI doesn't include by default, made by Microsoft or other developers.
Works best with:Special use cases, like word clouds, org charts, or industry-specific charts.
